# Sample videos

Drop your own test clips here (ignored by git, so they won't bloat the repo).

For best results:
- Film from a **true side view** (camera perpendicular to the direction you face).
- Keep the **whole body in frame** for the entire set, including feet.
- 3-5 reps, decent lighting, minimal camera shake.
- `.mp4` or `.mov`, any resolution — the pipeline normalizes measurements per
  frame so it isn't sensitive to camera distance.

Then run:

```
python main.py sample_videos/your_clip.mp4
```
